# UI/UX Guidelines

## 1. Portal Santri

### Principles

- Warna cerah tetapi tidak berlebihan.
- Tombol besar.
- Ikon jelas.
- Teks singkat.
- Dukungan suara.
- Feedback langsung.
- Hindari istilah akademik.
- Hindari label negatif.

### Main Navigation

- Beranda
- Pilih Jalanmu
- Bioskop Teladan
- Berani Menolak
- Pohon Kebaikan
- Profil

### Test Screen

- Satu kasus per layar.
- Progress indicator.
- Tombol putar suara.
- Ilustrasi cerita.
- Pilihan jawaban berbentuk kartu.
- Tombol rekam besar.
- Indikator sedang merekam.
- Tombol putar ulang.
- Autosave.
- Konfirmasi sebelum submit.

### Goodness Tree

- Pohon bertumbuh berdasarkan reward points.
- Menampilkan bintang, daun, atau buah.
- Tidak menunjukkan skor moral mentah.
- Gunakan kata motivasional.

## 2. Portal Ustadz

### Dashboard

- Jumlah santri.
- Pending review.
- Warning terbuka.
- Observasi terbaru.
- Distribusi level.
- Tren perkembangan.
- Filter periode dan kelompok.

### Review Page

Layout yang disarankan:

```text
Cerita dan pilihan
|
Audio player
|
Transkripsi
|
Hasil AI
|
Form validasi ustadz
```

### Observation Form

- Pilih santri.
- Checklist indikator.
- Positive/negative/neutral.
- Reward points.
- Catatan singkat.
- Simpan cepat.

## 3. Portal Admin

- User management.
- Academic structure.
- Test management.
- Indicator settings.
- Scoring settings.
- Content management.
- Tree levels.
- Audit log.

## 4. Responsive Breakpoints

- Desktop lab sebagai prioritas utama.
- Tablet sebagai prioritas kedua.
- Mobile tetap didukung.
- Komponen interaktif santri harus tetap mudah disentuh.

## 5. Accessibility

- Kontras teks memadai.
- Tidak mengandalkan warna saja.
- Caption atau transkrip untuk media.
- Kontrol keyboard.
- Focus state terlihat.
- Label form jelas.
- Audio dapat diputar ulang.
