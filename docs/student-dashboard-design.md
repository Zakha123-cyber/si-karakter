# Student Dashboard UI Design Prompt

Project: SI-KARAKTER (TeladanKu)

Role:
Senior UI/UX Designer
Senior Product Designer
Children Educational App Designer

---

# Objective

Design a modern dashboard homepage for elementary-age Islamic students (6–10 years old).

The interface should feel joyful, friendly, colorful, educational, and motivating.

The visual quality should be comparable to modern educational applications and premium mobile/web products.

This dashboard is the first page students see after logging in.

The goal is to make children excited to continue learning good character every day.

---

# Overall Design Style

Create an interface inspired by:

- Duolingo
- Khan Kids
- Lingokids
- Pok Pok
- Khan Academy Kids

combined with

Modern SaaS UI

and

Islamic educational identity.

The interface should look like a premium children's application, NOT like a school information system.
